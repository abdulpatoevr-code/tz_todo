# Интернет-магазин (E-Commerce Platform)

Полнофункциональный учебный интернет-магазин с разделённой архитектурой:
- **Backend:** Django 5.x + Django REST Framework (DRF) + JWT + SimpleJWT + SQLite + drf-spectacular (Swagger).
- **Frontend:** React 18 (Vite) + React Router v6 + Zustand + Axios + Lucide Icons.
- **Admin:** Стандартная Django Admin панель.

## 🚀 Быстрый старт

### 1. Запуск Backend (Django REST Framework)

1. Откройте терминал в папке проекта:
   ```bash
   cd backend
   ```

2. Активируйте виртуальное окружение:
   - **Windows:**
     ```powershell
     .venv\Scripts\activate
     ```
   - **Linux / macOS:**
     ```bash
     source .venv/bin/activate
     ```

3. Установите зависимости (если создаёте новое окружение):
   ```bash
   pip install -r requirements.txt
   ```

4. Примените миграции:
   ```bash
   python manage.py migrate
   ```

5. Наполните базу тестовыми товарами, категориями, картинками и пользователями:
   ```bash
   python manage.py seed_data
   ```

6. Запустите сервер разработки:
   ```bash
   python manage.py runserver 127.0.0.1:8000
   ```
   Сервер будет доступен по адресу: `http://127.0.0.1:8000/`

---

### 2. Запуск Frontend (React + Vite)

1. Откройте второй терминал и перейдите в папку `frontend`:
   ```bash
   cd frontend
   ```

2. Установите зависимости (если запускаете впервые):
   ```bash
   npm install
   ```

3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
   Клиент откроется по адресу: **`http://localhost:5173/`**

Для проверки работоспособности всех эндпоинтов выполните:
```bash
python backend/test_api.py
```
Скрипт проверяет:
- Получение категорий (`/api/categories/`)
- Список товаров с пагинацией по 12 шт (`/api/products/`)
- Фильтрацию по категории, цене, наличию
- Поиск товаров по названию
- Детальную карточку товара с похожими товарами

- Создание заказа гостем и авторизованным клиентом (`/api/orders/`)
- Получение истории заказов

## 🌟 Реализованные возможности

### 1. Каталог и товары
- Фильтрация по категории, диапазону цен («от» и «до»), флагу «только в наличии».
- Сортировка: по новизне, по возрастанию/убыванию цены, по названию.
- Постраничная пагинация (по 12 товаров на страницу).
- Карточка товара с галереей изображений, переключением превью, выбором количества, блоком похожих товаров из той же категории.

### 2. Корзина и Оформление заказа
- Корзина сохраняется в LocalStorage и доступна гостям и зарегистрированным пользователям.
- Добавление, удаление, изменение количества (±).
- Подсчёт суммы заказа.
- Оформление заказа с выбором способа доставки (курьер / самовывоз) и оплаты (наличные / картой).
- Автоматическое вычитание остатков на складе при заказе.
- Страница «Спасибо за заказ» с номером и деталями созданного заказа.

### 3. Авторизация и Личный кабинет
- JWT авторизация (Access + Refresh токены) с автообновлением токена.
- Регистрация с проверкой паролей и уникальности email.
- Отображение имени пользователя в шапке сайта.
- Редактирование профиля (имя, email, телефон).
- История заказов со статусами («Новый», «В обработке», «Отправлен», «Доставлен», «Отменён») и раскрывающимися списками товаров.

### 4. Поиск
- Живой поиск товаров по названию и описанию (`/search?q=...`) с выводом карточек или экрана «Ничего не найдено».

### 5. Django Admin
- Управление категориями (дерево категорий, активность).
- Управление товарами с инлайн-загрузкой фото (`ProductImageInline`).
- Управление заказами с инлайном позиций (`OrderItemInline`) и сменой статусов.
